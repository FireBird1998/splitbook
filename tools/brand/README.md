# Brand export tooling

Node.js 22+. Run from the repository root:

```sh
npm ci --prefix tools/brand --ignore-scripts
npm run build --prefix tools/brand
npm run check --prefix tools/brand
```

See [`docs/design/brand/README.md`](../../docs/design/brand/README.md) for asset selection, custom sizes and app integration. Source geometry, licensed font and export presets live in `assets/brand/`. The tool uses only these local inputs. Standard build replaces its own generated files; custom exports require a new destination filename.

`--check` compares every generated byte against the saved outputs, checks native icon opacity and verifies the Android foreground and monochrome layers fit the circular safe region. The asset manifest records dimensions, alpha-channel presence and SHA-256 hashes. PNG codec versions can differ across platforms; regenerate and review intentional differences when changing Node, sharp or its native libraries.
