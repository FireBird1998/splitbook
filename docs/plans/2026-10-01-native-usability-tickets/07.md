# 07 Prototype the compact Android form and navigation

Status: draft awaiting ticket-breakdown review; proposed label `ready-for-agent`.

## What to build

Produce and review an OpenDesign Local Codex prototype for the native surface, including realistic errors and refresh states.

## Acceptance criteria

- [ ] Show compact Amount/Description entry, date/payer/split/Tag selectors, optional details, allocation review and keyboard-aware Save.
- [ ] Define bottom navigation destinations and Group-to-Expense return behavior explicitly without inventing unsupported global Activity data.
- [ ] Include initial, cached refresh, invalid input, unavailable offline, ordinary draft and uncertain submission states.
- [ ] Use semantic tokens, Outfit and IBM Plex Mono; cover light/dark, small display and large text.
- [ ] Provide a navigable prototype and record the user review decision; unavailable OpenDesign remains an explicit blocker, not a substitute mockup presented as approved.
