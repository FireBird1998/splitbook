# 03 Keep financial content visible during refresh

Status: draft awaiting ticket-breakdown review; proposed label `ready-for-agent`.

## What to build

Keep the current authorized view readable while refreshing and show one progress cue appropriate to the operation.

## Acceptance criteria

- [ ] Same-resource refresh retains loaded content; automatic refresh does not activate the native pull indicator.
- [ ] Use full initial loading only without usable matching data, manual pull feedback only for a pull, and a pagination footer for additional pages.
- [ ] Background failure retains prior data with its actual timestamp and an actionable warning.
- [ ] Changing Month never labels previous Expenses as the new Month; running Balances remain all-time.
- [ ] Preserve Expense materialization before fresh Balance publication; mark retained prior Balances updating rather than current.
- [ ] Access denial and account changes still remove protected data immediately; test loading, error, denial and out-of-order responses at the public seam.
