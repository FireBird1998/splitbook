# 04 Reuse cached views and coalesce foreground reads

Status: draft awaiting ticket-breakdown review; proposed label `ready-for-agent`.

## What to build

Show validated matching cached content promptly and combine redundant foreground/reconnect requests without weakening authorization.

## Acceptance criteria

- [ ] Overlapping same-key refresh requests share one in-flight read; invalidation during that read still schedules needed later work.
- [ ] Begin with a measured, adjustable 30-second display freshness policy; manual refresh and confirmed writes bypass it.
- [ ] Preserve cache timestamps, environment/account/Group/filter identity and account cleanup ordering.
- [ ] Confirmed Expense create/edit/delete and Settlement changes invalidate affected pages, Month summaries, Balances, Home and Activity; old responses cannot overwrite newer state.
- [ ] Foreground/reconnect never replays a financial write or replaces an unfinished draft.
- [ ] Uncached offline and failed requests reach actionable terminal states; record request counts and cold/warm timings; test denial, late response and restart boundaries.
