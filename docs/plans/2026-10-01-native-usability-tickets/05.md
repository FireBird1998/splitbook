# 05 Clarify draft recovery history and return navigation

Status: draft awaiting ticket-breakdown review; proposed label `ready-for-agent`.

## What to build

Resume and recover Expenses predictably, explain edits in human terms, and return to the originating Group and Month.

## Acceptance criteria

- [ ] Return from an Expense restores its known Group/Month and appropriate scroll context; direct entry has an explicit fallback.
- [ ] Resuming an ordinary draft removes obsolete resume warnings and preserves all entries.
- [ ] Uncertain submission recovery remains distinct; explicit retry retains immutable payload, identity and revision protections.
- [ ] Edit history formats money, dates and member names with safe former-member fallbacks; raw JSON and database identifiers are absent.
- [ ] Verify restart, conflict, response loss, back navigation and late completion through public-controller and installed Android journeys.
