# Production and staging databases are kept apart, with least privilege and backups we run ourselves during the beta

Until 22 October 2026, production and staging shared one free Atlas cluster (M0), and production's app user could read and write every database on it, staging's included (#826). Staging now has its own Atlas project ("Splitbook Staging") with its own free cluster, and starts empty. Production stays exactly where it was: its data was never moved, because the owner's first rule is that production's data, which includes a Group that must never be harmed, is never put at risk. Each environment's app user reads and writes only its own database, no app user is an admin, and the admin user never goes into an app's settings. The owner confirmed this in the #826 grilling.

Both projects deliberately let any IP connect (`0.0.0.0/0`, labelled with this ADR). Vercel's Hobby plan has no fixed outbound IPs: fixed IPs need Vercel Pro plus $100 a month per project, and private networking needs a dedicated (M10+) cluster and Vercel Enterprise. For the beta (the owner and four friends), we rely on per-environment users with long random passwords and the TLS Atlas always enforces. We revisit this when the app moves to Vercel Pro.

A free cluster has no backups. We did not upgrade production's cluster to Flex to get them: Atlas documents that the upgrade needs downtime with writes halted, but not how long it takes, whether the connection address and indexes survive, or any way back to free. That is the riskiest change we could make to the cluster holding that Group. Instead, a read-only user (`read` on production's database only) dumps production nightly on the owner's Mac with `tools/db-backup`. Each dump is read back and counted, the newest 14 are kept, and a restore can be proven at any time with a throwaway local database (`docs/runbooks/database-backups.md`). The cost is that a backup runs only while that Mac is on, catching up when it wakes. At launch beyond the beta, production moves to a paid tier with automatic backups, alongside Vercel Pro.
