# T06 — Revise and permanently discard Drafts on both clients

## What to build

Members correct or permanently remove individual Drafts on web and Android without overwriting a newer revision.

## Acceptance criteria

- [ ] Allow editing incomplete values and clearing previously entered facts; require an expected revision for edit and discard.
- [ ] Reject stale web/Android changes and require refresh; preserve the member’s unsent correction for deliberate reconciliation.
- [ ] Clearly explain permanent discard before the member action; remove content and free Group capacity without a recovery view.
- [ ] Retrying the original creation or discard cannot resurrect removed content; retain only necessary replay metadata.
- [ ] Test cross-client races, foreign-owner IDs and membership removal; both clients refresh to the same outcome.
