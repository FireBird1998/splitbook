# T08 — Save a selection with per-Draft outcomes

## What to build

Members select multiple Drafts in either client and save valid items while failures remain for correction.

## Acceptance criteria

- [ ] Provide selection, review and duplicate acknowledgment on web and Android.
- [ ] Process each selected Draft independently with the exact reviewed revision; return saved, failed or unresolved per-item results.
- [ ] Keep failed Drafts and explain corrections; never report a timeout as a confirmed failure or success.
- [ ] Retry unresolved items with stable operation identities, without recreating successful Expenses.
- [ ] Test mixed valid/incomplete/duplicate/stale selections and interruption recovery through both clients and the authenticated boundary.
