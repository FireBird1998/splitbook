# T10 — Revise and discard Drafts from a connected assistant

## What to build

An authorized assistant corrects or permanently discards the member’s Drafts and both clients show the result.

## Acceptance criteria

- [ ] Expose revision-aware edit and permanent-discard tools with accurate descriptions and destructive annotations.
- [ ] Stale changes require fetching current state; no silent overwrite of a web or Android correction.
- [ ] Apply Draft scope, live grant and membership checks at the operation boundary; never expose an Expense save tool.
- [ ] Remove content permanently, free the owner’s capacity in the Group and prevent resurrection from retries.
- [ ] Demonstrate manual Draft edits by the assistant, assistant discard visible on both clients, stale-version rejection and revocation during authorization.
