# T11 — Verify and enable the complete connected-Draft journey

## What to build

The release is enabled only after both assistant hosts and both review clients complete the approved experience.

## Acceptance criteria

- [ ] On staging, connect actual ChatGPT and Claude, read Balances/spending, prepare multiple incomplete Drafts, close chat, and review/save on web and native Android.
- [ ] Exercise disconnect/reconnect, scope denial, changed account eligibility, removed/rejoined membership, Group/account deletion and quota races across clients.
- [ ] Confirm Android recovery never uploads or saves on reconnect; verify mixed outcomes and retries do not duplicate ledger effects.
- [ ] Apply bounded inputs, request limits and privacy-safe diagnostics at exposed boundaries; verify private responses are not cached.
- [ ] Run repository-required checks and document results, remaining host/account limitations, deployment prerequisites and rollback/disable procedure.
- [ ] No public rollout while either required client or host acceptance is incomplete; directory publication remains separate.
