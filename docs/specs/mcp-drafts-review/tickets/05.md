# T05 — Keep and revisit the shared collection on Android

## What to build

Android members retain incomplete expenses online and see the same private Drafts as on web.

## Acceptance criteria

- [ ] Add native Keep as Draft and collection listing using shared pure validators and the authenticated backend.
- [ ] Clearly distinguish the online collection from existing local form recovery; no automatic upload on reconnect.
- [ ] Preserve payload and request identity until upload acknowledgment, including unknown outcomes.
- [ ] Resolve any uncertain existing Expense save before creating a Draft from recovered content.
- [ ] Demonstrate web-to-Android visibility, quota errors, membership rejection and offline/reconnect recovery without duplicate writes.
