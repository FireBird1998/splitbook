# T01 — Connect and revoke an assistant

## What to build

A member connects an assistant over public HTTPS, verifies the connection, and disconnects it from SplitBook Settings.

## Acceptance criteria

- [ ] Provide discovery, consent, authorization-code PKCE, token refresh and a synthetic connection-status tool in the existing backend.
- [ ] Consent describes all current and future Groups and separate Draft permission including permanent discard; store authoritative connection identity and authorization generation.
- [ ] Connection Settings permit revocation; unexpired and refreshed tokens from the revoked generation cannot regain access after reconnecting.
- [ ] Check current account eligibility and reject browser cookies as a substitute for MCP bearer authorization.
- [ ] Verify real SDK calls plus actual ChatGPT and Claude setup on staging; record supported protocol/client-registration paths and any blockers. Keep ledger and Draft tools unavailable in this slice.

## Blocked by

None — can start immediately
