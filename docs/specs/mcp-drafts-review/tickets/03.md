# T03 — Answer spending questions through a connected assistant

## What to build

Members ask about expenses and spending within an authorized Group and receive bounded, understandable answers.

## Acceptance criteria

- [ ] Return authorized Expense details and spending summaries with explicit date range, timezone and currencies.
- [ ] Bound result sizes and support continuation where needed; do not mix currencies or silently omit data from a claimed total.
- [ ] Use canonical ledger rules and preserve read-only behavior, membership checks and connection revocation.
- [ ] Test date boundaries, pagination, mixed currencies and permission failures through MCP; demonstrate a spending question against known ledger data.
