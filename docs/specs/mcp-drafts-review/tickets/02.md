# T02 — Read Group Balances through a connected assistant

## What to build

An authorized assistant discovers current Groups and answers Balance questions using canonical SplitBook results.

## Acceptance criteria

- [ ] Extract only the actor-aware read operations needed by this slice and reuse them across adapters without changing existing client results.
- [ ] Enforce ledger scope, live grant status and current Group membership; exclude unauthorized Groups and private Drafts.
- [ ] Preserve per-currency money semantics and explain the Balance context.
- [ ] Assistant reads do not materialize recurring Expenses; define parity with the existing recurring-expense lifecycle and test that reads leave the ledger unchanged.
- [ ] Demonstrate Group discovery and Balance answers through the official MCP client and a connected host.
