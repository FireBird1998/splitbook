# T09 — Prepare persistent Drafts from a connected assistant

## What to build

A member asks an assistant to prepare several expenses, then follows a SplitBook link to the retained collection.

## Acceptance criteria

- [ ] Gate list/create tools on separate Draft permission and current grant, account and membership checks.
- [ ] Operate only on the connection owner’s collection, including manual Drafts; ledger-only access reveals none.
- [ ] Create up to 10 incomplete Drafts with explicit missing facts and exact replay identity; enforce the Group-wide 100 limit via the same operations as manual creation.
- [ ] Return a usable authenticated review link and explain that saving occurs in SplitBook; show actionable capacity/validation outcomes.
- [ ] Check grant state at write authorization and test revocation, future Group membership, spoofed owners and identical retries.
- [ ] Demonstrate assistant creation followed by web review after closing the chat; keep this an internal slice until Android and save work is complete.
