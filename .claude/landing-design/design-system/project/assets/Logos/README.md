# Logos

The Equal share identity from `assets/brand/svg`, copied unchanged. Every file is filled paths with fixed inks (no `currentColor`), so pick the variant for the ground.

- `logo-light.svg` — mark and wordmark in logo-indigo #6366F1 and ink. Headers on white or paper, 32px high.
- `logo-dark.svg` — the same in logo-indigo-on-dark #7B8CFF and white. Headers on ink or dark surfaces.
- `logo-ink.svg` — single ink #172033, for one-colour print on light grounds.
- `logo-white.svg` — single ink white, for solid saturated or dark grounds (invisible on this page's light tiles).
- `mark-indigo.svg` — the mark alone in #6366F1, 24–48px, on light grounds.
- `mark-on-dark.svg` — the mark in #7B8CFF, on dark grounds.
- `mark-ink.svg` — the mark in ink #172033.
- `mark-white.svg` — the mark in white, on dark or indigo fills.
- `stacked-light.svg`, `stacked-dark.svg` — mark above wordmark, for large centred branding at 200px wide or more.
- `wordmark-light.svg`, `wordmark-dark.svg` — the name alone, outlined Outfit Bold, 16px high or more.
- `app-icon.svg` — the primary app icon: white mark on ink #172033.
- `app-icon-indigo.svg` — a marketing alternate on indigo.
- `favicon.svg` — the browser-tab icon.
