## What to build

Make it possible for a member to let a Connected assistant prepare expenses for their To review. That's the main promise of #403, and staging showed it blocked.

- **The connect challenge.**
  - While persistent Drafts are switched on, Splitbook invites a connecting assistant to ask for both permissions: reading the ledger, and preparing items for To review.
  - Read access alone is still enough to connect, so a member who doesn't allow preparing items keeps a working read-only connection.
  - With Drafts switched off, nothing changes.
- **The permission screen.**
  - The second permission appears as an **unticked** choice.
  - **Checkbox:** "Also let it prepare expenses for your To review".
  - **Help line:** "It can add, change and delete items in your To review. Only you can save them as expenses, in Splitbook."
  - **Notice:** "Prepared items don't change Balances until you save them."
  - **Footer:** "Your To review items stay yours."
  - Nothing on this screen says "Draft".
- **The result:** ticking it gives the assistant the tools to prepare items; leaving it unticked gives read access only.
- **Existing connections:** a member with a read-only connection gets the new permission by disconnecting and reconnecting. Add one line saying so to the MCP connections runbook.

## Acceptance criteria

- [ ] With Drafts on, an anonymous request to the MCP endpoint gets a challenge that names both scopes, and access still requires only the ledger scope. With Drafts off, the challenge names the ledger scope only.
- [ ] A connection test that follows the server's own challenge, asking only for the scopes it names, reaches a permission screen offering the Draft permission.
  - Consenting **with** it gives a tool list that includes the Draft tools.
  - Consenting **without** it gives the ledger tools only.
  - The test must not inject the Draft scope itself.
- [ ] The existing connection tests that request the Draft scope directly still pass unchanged.
- [ ] The permission screen shows the new wording, with the checkbox unticked by default. No "Draft" appears for members. A browser check covers the wording, in light and dark at 130% text, with axe passing.
- [ ] The MCP connections runbook says how to add the permission to an existing connection.
