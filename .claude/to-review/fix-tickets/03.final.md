## What to build

Small fixes to the web To review page and Home card, found in the staging QA.

- **"Save N ready" while an item is open:**
  - it stays available instead of being silently disabled;
  - pressing it first keeps any pending edit in the open item, then shows the normal confirmation for exactly the ready versions.
- **Nothing ready:** the "Save N ready" button is hidden when no item is ready, instead of reading "Save 0 ready".
- **Counts once:** each count ("1 needs details", for example) appears once in the summary, not twice.
- **No flash on Home:** the Home To review card renders nothing until the read shows items waiting, so a member with nothing waiting never sees it flash. The Group banner already works this way.

## Acceptance criteria

- [ ] With an item open and an edit still pending, Save N ready keeps the edit, then confirms. The confirmation shows the kept version.
- [ ] With zero ready items, there's no Save N ready button. "Review one at a time" still works for the remaining items.
- [ ] The summary never repeats a count.
- [ ] Home with nothing waiting shows no To review card at any point while loading.
- [ ] Playwright journeys on the demo seed cover each point, in light and dark at 130% text, with axe passing.

## Blocked by

- #420: the web review panel rebuild. Both change the To review page and the panel's pending-edit handling.
